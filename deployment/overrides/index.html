추천 설정
현재 선택한 총기에서 원하는 능력치를 높이는 모딩을 자동으로 추천합니다.

 

 
낮은 반동과 안정성을 갖춘 간편 추천
실전 균형 추천은 수직·수평 반동 배율과 탄착 경로를 우선 줄입니다. 안정성·조작성의 무기별 최소 기준을 지키면서, 더 낮은 반동을 위해 조준 시간과 조준 이동속도를 조정할 수 있습니다. 총기 점수만으로 고르지 않습니다.
현재 모딩 유지·개선에서는 반동·안정성·조준·이동속도·탄속·사거리와 추가 비교 항목을 현재 값보다 나빠지지 않도록 제한합니다. 배제한 계열은 보호·평가에서 빠집니다. 개선을 찾지 못하면 현재 모딩을 유지하며, 종결이라고 확정하지 않습니다.
손해 없는 개선만 원할 때는 현재 모딩 유지·개선을 선택하세요. 기존 균형 추천도 별도로 남겨두었습니다. 조준경 조건과 잠긴 파츠 제외는 두 방식 모두에 적용합니다.
간편 추천에서 제외할 스탯
체크한 계열은 평가와 자동 최소 조건에서 모두 제외합니다. 그 수치만 높이는 파츠는 제거하며, 남은 목표에 도움이 되거나 조준경 장착에 필요한 파츠만 유지합니다.
이 무기의 자동 기준 보기

 
 
실전 평가는 수직·수평 반동과 발사 시 무기 흔들림을 함께 봅니다. 점수 목표는 관련 세부수치로 평가하고, 같은 계열 목표를 여러 개 넣어도 계열 비중이 중복 증가하지 않습니다. 필수 수치 제한과 우선순위는 유지합니다. 실제 명중률·체감을 보장하는 모델은 아닙니다.

 
마음에 드는 모딩을 먼저 장착한 뒤 체크하면, 해당 세팅을 기준으로 반동 조건을 유지하며 다른 목표를 개선할 후보를 찾습니다.
최적화 평가에서 제외할 스탯
체크한 스탯은 목표 평가에서 제외하고, 해당 스탯에만 효과가 있는 단독 파츠도 자동 선택에서 제외합니다. 다른 목표에도 도움이 되는 겸용 파츠는 선택될 수 있습니다. 실제 수치, 고정 파츠와 직접 지정한 수치 제한은 유지합니다.

 

 

 
목표 옆에서 우선순위를 정하세요. 상위 목표가 같을 때 다음 순위를 비교합니다. 같은 순위의 목표는 기본 무기 대비 변화율을 같은 비중으로 비교합니다. 조준경·수치 제한 등 필수 조건을 먼저 만족시킵니다.


고급 설정 · 수치 제한 / TTK 기준
꼭 지켜야 할 수치가 있을 때만 제한을 추가하세요. 입력하지 않아도 탐색할 수 있습니다.

 
TTK는 상체 연속 명중 기준이며 탄환 비행 시간과 명중률은 제외합니다.

잠금 해제·보유 여부는 자동으로 알 수 없습니다. 미보유 파츠는 제외 목록에서 선택하세요. 특수 발사 무기는 TTK 최적화를 지원하지 않습니다.



  

 
무배율은 원본 광학 배율 2배 미만, 배율은 최대 2배 이상(가변 포함)으로 구분합니다. 높이 조절대와 그 위의 조준경도 함께 탐색합니다. 측면·보조 조준경만으로는 필수 조건을 충족하지 않습니다.
  


미보유·잠긴 파츠 제외 
게임에서 쓸 수 없는 파츠를 체크하세요. 간편·고급 모두에서 제외하며 이 브라우저에 저장합니다. 추천 파츠를 다른 것으로 바꾸면 전체 수치가 달라지므로, 장착 가능한 파츠로 다시 탐색하세요.
고급 목표·수치 제한·파츠 고정은 간편 추천에 적용하지 않습니다. 미보유 파츠 제외·조준경·전술 효과·총성 감소 조건은 두 모드에 공통으로 적용합니다.

 
조준경을 선택하고 간편 추천 찾기를 누르세요.

게임에서 발급한 공유 코드
공개 생성 규칙·API를 확인하지 못해 델타랩에서 게임용 코드를 새로 만들 수 없습니다. 게임에서 아래 파츠·보정을 적용한 후 ‘장비 공유’로 발급한 코드를 연결하세요.

  2. 게임 총기 개조에서 같은 조합을 장착하고 장비 공유로 코드를 발급합니다.
  3. 코드를 아래에 등록하면 동일한 세팅에서 다시 복사할 수 있습니다.

 
사용자 확인 코드만 저장합니다. 델타랩은 게임 서버의 유효성을 검증하거나 플랫폼 간 코드를 변환하지 않습니다. 다른 파츠·보정·데이터 버전에서는 자동 연결하지 않습니다.
