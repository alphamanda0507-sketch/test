# DELTA LAB KR

델타포스 전면전 총기 모딩 계산기. 69종 무기와 583개 파츠를 지원하는 비공식 팬 도구입니다.

온라인: https://alphamanda0507-sketch.github.io/test/

데이터 출처: https://dfttk.com/battlefield/builder

현재 모딩 유지·개선 / 균형 추천 / 스탯 배제 / 파츠 호환성과 중첩 조준경 / 정밀 보정을 지원합니다. 제한된 탐색이며 전역 최적값을 보장하지 않습니다. DFLAB1 코드는 델타랩 복원용이며 게임용 공유 코드가 아닙니다.

## 배포

`deployment/site.tar.gz.part-*`를 이름 순서대로 합친 tar.gz에 전체 정적 사이트와 원본 데이터가 들어 있습니다. GitHub Actions가 체크섬을 검증하고 압축을 풀어 GitHub Pages에 배포합니다. 방문자는 압축을 풀거나 로그인할 필요가 없습니다. 파일별 원본은 다음과 같이 복원할 수 있습니다.

```sh
cat deployment/site.tar.gz.part-* > site.tar.gz
mkdir public
tar -xzf site.tar.gz -C public
```

현재 배포 파일은 `clear-recommendations-20261110-r24`입니다. `deployment/overrides/`의 수정 파일을 기본 정적 사이트 위에 적용합니다. 최근 추천 UI와 최적화 로직은 이 폴더의 읽기 가능한 소스 파일에서 관리합니다. 데이터는 수집한 스냅샷이며 원본 사이트 변경을 실시간 자동 반영하지 않습니다. 무기 외형 이미지 조각은 원본 사이트에서 불러옵니다.

## 실전 균형 추천 기본값

기본 추천은 인게임 AKM의 기본값 대비 개선 비율을 각 무기에 적용합니다. 기준 AKM은 수직·수평 반동 0.76배, 발사 흔들림 0.64배, 조준 242ms, 조준 이동속도 3.04m/s입니다. 반동 제어를 평가하는 경우 발사 시 무기 흔들림은 각 무기 기본값의 64% 이하를 충족해야 합니다. 무기별 최소 스탯과 사거리·포구속도 보호 조건을 먼저 적용한 뒤 목표에 부족한 정도를 비교합니다. 탄착 경로는 후보 비교에도 사용합니다.

## 피드백 재추천

간편 추천 후보에서 안정성, 조준 시간, 조준 중 이동속도, 반동에 관한 피드백을 복수 선택하고 다시 추천할 수 있습니다. 선택한 후보의 파츠와 정밀 보정을 기준으로 계산하며, 기본은 다른 비교 항목도 유지합니다. 사용자가 직접 선택한 경우에만 비대상 비교 항목의 최대 5% 손해를 허용합니다. 전후 수치와 악화 항목을 표시하고 이전 추천으로 되돌릴 수 있습니다. 조건에 맞는 개선을 찾지 못하면 기존 모딩을 유지합니다.

## 사거리·포구속도 보호

간편 추천의 모든 방식에서 사거리와 포구속도는 기본 총기 값 이상이어야 합니다. 현재 모딩 유지·개선과 피드백 재추천에서는 현재 후보의 값도 낮추지 않습니다. 두 항목은 5% 손해 허용 대상에서 제외하며, 최소 기준을 충족하지 못하는 후보는 적용할 수 없습니다. 사거리와 포구속도를 더 높이는 피드백도 선택할 수 있습니다. 69종 무기의 세 가지 간편 추천 방식, 총 207개 실행 조건을 검사했습니다.


## 조준·안정성 비율 조정

안정성 기준은 인게임 AKM의 호흡 흔들림 0.23°, 이동 흔들림 0.58배, 사격 카메라 흔들림 평균 0.23배, 숨 참기 38.8초와 숨 참기 반동 0.82배입니다. 조준 시간·이동속도와 함께 질주 후 사격 지연 108ms도 비교합니다.


## 현재 공통 균형 모델과 추가 기능

현재 추천은 선호 사례의 기본 총기 대비 개선 비율까지 부족한 정도를 비교합니다. 목표를 초과한 한 항목의 개선으로 다른 항목의 부족을 상쇄하지 않습니다. 반동 0.2 / 발사 흔들림 0.2 / 안정성 0.4 / 조준·이동 0.2의 공통 가중치를 사용합니다. 배제한 계열은 제거하고 나머지 가중치를 재정규화합니다. 69종의 별도 후보 탐색에서 얻은 시작 조합도 현재 조건으로 재검사합니다. 이는 제한된 탐색이며 전역 최적 또는 게임 실측 성능 보장이 아닙니다. 검증 조건을 충족하지 못한 무기도 보고서에 그대로 남깁니다.

간편·고급·피드백 추천에서 전술장비를 제한 없음, 미장착, 라이트 전용, 레이저 전용, 겸용으로 선택할 수 있습니다. 유형을 지정하면 호환 장비 한 개를 장착해야 충족으로 표시합니다. 레이저 장착 시 기본 화면과 추천 후보에 OFF/ON 점수와 변화한 세부 수치를 함께 표시합니다. 장착 자체의 상시 감소는 OFF에서도 계산합니다. 지원되는 전술 효과를 함께 전환하므로 게임과 항목 대응이 완전히 검증됐다는 의미는 아닙니다. 간편 추천의 탄창 용량은 제한 없음, 기본 용량, 확인된 정확한 발수 중 선택합니다. 용량 또는 다른 필수 기준을 만족하지 못하면 후보를 적용할 수 없습니다.


## 피드백의 다른 파츠 후보

피드백 재추천은 서로 다른 파츠 구성별 최선의 보정을 보관하고, 두 파츠를 함께 바꾸는 조합도 탐색합니다. 보정값만 다른 후보는 하나로 묶고, 같은 파츠를 다른 레일로 옮기는 경우도 별개 파츠 구성으로 세지 않습니다. 조건을 만족하는 범위에서 최대 5개를 보여주며, 총열·개머리판·손잡이·탄창 등 주요 파츠가 다른 조합을 우선 분산해 표시합니다. 바뀐 장착 위치와 전후 파츠 이름을 후보마다 표시합니다. 피드백 개선을 찾지 못하면 손해 없는 다른 구성과 기존 모딩을 비교할 수 있고, 대안 개수를 보장하지 않습니다. 미보유 파츠, 조준경, 탄창 용량, 사거리·포구속도와 기타 보호 조건은 유지합니다. 검증: `deployment/overrides/data/feedback-diversity-validation.json`.


## 조건 미충족 후보 직접 적용

현재 버전에서는 조건을 충족하지 못한 후보도 사용자가 직접 적용하거나 저장·공유할 수 있습니다. 추천 순위와 충족 판정, 미충족 항목, 전후 수치 경고는 유지하며 적용했다고 충족으로 바꾸지 않습니다. 피드백 재추천에서 유효한 조합이 없을 때에도 가장 가까운 파츠 후보를 남깁니다. 호환성 계산과 미보유 파츠 제외는 그대로입니다.


## 사진으로 조준경 선택

추천 설정에서 조준경을 포함하는 조건을 선택하면 해당 무기에 호환되는 조준경의 사진·한국어 이름·배율을 표시합니다. 자동 선택 또는 특정 제품을 선택할 수 있으며, 특정 조준경을 선택하면 간편·고급·피드백 추천에 반영합니다. 실전 균형은 조건을 충족한 후보 중 다용도 전술 높이 조절대 위에 마이크로 높이 조절대를 중첩하는 조합을 먼저 추천합니다. 선택한 조준경을 장착할 수 있는 높이 경로를 비교하며, 중첩이 어려우면 단일 조절대나 직접 장착도 사용합니다. 배율 조건·제외 파츠·고정 파츠가 충돌하면 실행 전에 안내합니다. 원본 이미지가 로드되지 않으면 사진 없음으로 표시합니다.

조준경 사진 38종은 원본 PNG에서 만든 WebP 썸네일을 사이트에 포함해 외부 서버의 참조 주소 차단에 영향을 받지 않도록 했습니다. 사진 출처와 원본 해시는 data/optic-images/sources.json에 기록되어 있습니다.
