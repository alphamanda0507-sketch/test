## 배포

`deployment/site.tar.gz.part-*`를 이름 순서대로 합친 tar.gz에 전체 정적 사이트와 원본 데이터가 들어 있습니다. GitHub Actions가 체크섬을 검증하고 압축을 풀어 GitHub Pages에 배포합니다. 방문자는 압축을 풀거나 로그인할 필요가 없습니다. 파일별 원본은 다음과 같이 복원할 수 있습니다.

```sh
cat deployment/site.tar.gz.part-* > site.tar.gz
mkdir public
tar -xzf site.tar.gz -C public
```

현재 배포 파일은 `codmunity-20261107-r15`입니다. `deployment/overrides/`의 수정 파일을 기본 정적 사이트 위에 적용합니다. 최근 추천 UI와 최적화 로직은 이 폴더의 읽기 가능한 소스 파일에서 관리합니다. 데이터는 수집한 스냅샷이며 원본 사이트 변경을 실시간 자동 반영하지 않습니다. 무기 외형 이미지 조각은 원본 사이트에서 불러옵니다.

## 실전 균형 추천 기본값

기본 추천은 수직·수평 반동 배율과 제공된 탄착 경로의 상승·가로폭·급격한 이동을 먼저 평가합니다. 안정성·조작성의 무기별 최소 기준을 유지하며 조준 시간과 조준 이동속도의 일부 손해를 허용합니다. 호흡·이동·카메라 흔들림은 기본 총기의 60% 이하로 제한하고, 안정성 평가 비중을 높이고 카메라·이동 흔들림 개선을 더 오래 반영하여 작은 반동 이득으로 큰 안정성 손해를 덮지 않도록 평가합니다. 새 수치 비교 사례에서는 반동 0.61배·카메라 흔들림 0.12배인 선호 사례가 반동 0.59배·카메라 흔들림 0.23배인 최근 사례보다 높은 순위를 받습니다. 제외한 계열은 평가와 해당 보호 조건에서도 제외합니다. 현재 값보다 손해 보지 않는 기존 방식은 ‘현재 모딩 유지·개선’으로 선택할 수 있습니다. AKM 비교 사례와 69종 무기 실행을 검사했으며, 전수 탐색이나 실제 게임 성능을 보장하지 않습니다. 실전 균형에서도 사거리와 포구속도는 기본 총기와 현재 모딩 값 이상으로 보호합니다.

## 피드백 재추천

간편 추천 후보에서 안정성, 조준 시간, 조준 중 이동속도, 반동에 관한 피드백을 복수 선택하고 다시 추천할 수 있습니다. 선택한 후보의 파츠와 정밀 보정을 기준으로 계산하며, 기본은 다른 비교 항목도 유지합니다. 사용자가 직접 선택한 경우에만 비대상 비교 항목의 최대 5% 손해를 허용합니다. 전후 수치와 악화 항목을 표시하고 이전 추천으로 되돌릴 수 있습니다. 조건에 맞는 개선을 찾지 못하면 기존 모딩을 유지합니다.

## 사거리·포구속도 보호

간편 추천의 모든 방식에서 사거리와 포구속도는 기본 총기 값 이상이어야 합니다. 현재 모딩 유지·개선과 피드백 재추천에서는 현재 후보의 값도 낮추지 않습니다. 두 항목은 5% 손해 허용 대상에서 제외하며, 최소 기준을 충족하지 못하는 후보는 적용할 수 없습니다. 사거리와 포구속도를 더 높이는 피드백도 선택할 수 있습니다. 69종 무기의 세 가지 간편 추천 방식, 총 207개 실행 조건을 검사했습니다.


## 조준·안정성 비율 조정

실전 균형 추천은 조준 시간과 질주 후 사격 지연을 주 평가에 포함합니다. 조준 이동속도는 기본 총기보다 10% 빨라진 뒤에는 추가 가점을 주지 않아, 추가 속도만을 위해 안정성이나 조준 시간을 희생하지 않게 합니다. 실제 속도 계산과 보호 조건은 그대로입니다. 안정성 비중을 높여 사용자가 선호한 두 번째 AKM 사례와 비슷한 비율을 지향합니다. 모든 총기에 기본 총기 대비 비율로 적용하며, 정확히 같은 결과나 전역 최적값을 보장하지 않습니다.


## 현재 공통 균형 모델과 추가 기능

현재 추천은 선호 사례의 기본 총기 대비 개선 비율까지 부족한 정도를 비교합니다. 목표를 초과한 한 항목의 개선으로 다른 항목의 부족을 상쇄하지 않습니다. 8종에서 40회의 탐색과 64개 가중치 조합을 비교하고 별도 무기 검증을 거쳐, 반동·탄착 경로 0.2 / 발사 흔들림 0.2 / 안정성 0.4 / 조준·이동 0.2의 공통 가중치를 사용합니다. 배제한 계열은 제거하고 나머지 가중치를 재정규화합니다. 69종의 별도 후보 탐색에서 얻은 시작 조합도 현재 조건으로 재검사합니다. 이는 제한된 탐색이며 전역 최적 또는 게임 실측 성능 보장이 아닙니다. 검증 조건을 충족하지 못한 무기도 보고서에 그대로 남깁니다.

레이저 장착 시 기본 화면과 추천 후보에 OFF/ON 점수와 변화한 세부 수치를 함께 표시합니다. 장착 자체의 상시 감소는 OFF에서도 계산합니다. 지원되는 전술 효과를 함께 전환하므로 게임과 항목 대응이 완전히 검증됐다는 의미는 아닙니다. 간편 추천의 탄창 용량은 제한 없음, 기본 용량, 확인된 정확한 발수 중 선택합니다. 용량 또는 다른 필수 기준을 만족하지 못하면 후보를 적용할 수 없습니다.


## 피드백의 다른 파츠 후보

피드백 재추천은 서로 다른 파츠 구성별 최선의 보정을 보관하고, 두 파츠를 함께 바꾸는 조합도 탐색합니다. 보정값만 다른 후보는 하나로 묶고, 같은 파츠를 다른 레일로 옮기는 경우도 별개 파츠 구성으로 세지 않습니다. 조건을 만족하는 범위에서 최대 5개를 보여주며, 총열·개머리판·손잡이·탄창 등 주요 파츠가 다른 조합을 우선 분산해 표시합니다. 바뀐 장착 위치와 전후 파츠 이름을 후보마다 표시합니다. 피드백 개선을 찾지 못하면 손해 없는 다른 구성과 기존 모딩을 비교할 수 있고, 대안 개수를 보장하지 않습니다. 미보유 파츠, 조준경, 탄창 용량, 사거리·포구속도와 기타 보호 조건은 유지합니다. 검증: `deployment/overrides/data/feedback-diversity-validation.json`.


## 조건 미충족 후보 직접 적용

현재 버전에서는 조건을 충족하지 못한 후보도 사용자가 직접 적용하거나 저장·공유할 수 있습니다. 추천 순위와 충족 판정, 미충족 항목, 전후 수치 경고는 유지하며 적용했다고 충족으로 바꾸지 않습니다. 피드백 재추천에서 유효한 조합이 없을 때에도 가장 가까운 파츠 후보를 남깁니다. 호환성 계산과 미보유 파츠 제외는 그대로입니다.


## CODMunity 추천 모딩

총기 개조 화면에서 선택한 무기에 맞는 CODMunity 전면전 추천 모딩을 표시합니다. 무기 61종·추천 구성 64개의 부품 572개를 기존 계산기 ID와 중첩 장착 위치에 연결했습니다. 추천 선택 시 호환성 검사 후 기존 개조·외형·능력치 계산에 적용되며 원본 게임 공유 코드를 복사할 수 있습니다. 원본의 정밀 보정값은 제공되지 않아 웹 계산에는 기본값을 사용합니다. 게임 코드 원문은 변경하지 않으며 서버 간 변환이나 유효성 검증은 하지 않습니다. 출처와 수집 시각은 각 항목에 보존합니다. 파츠·보정을 직접 변경하면 원본 추천과 달라졌음을 표시합니다.
